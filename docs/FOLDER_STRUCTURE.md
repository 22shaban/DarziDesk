# DarziDesk Folder Structure

```text
DarziDesk/
  frontend/
  backend/
  docs/
  aws/
  scripts/
```

## frontend/
- React + Vite client application shell
- UI placeholders only (sidebar, top navbar, login, dashboard)

## backend/
- Flask REST API foundation
- Environment-driven configuration
- Health endpoint: `/health`
- Modular packages for routes, services, models, and utilities

## docs/
- Project documentation and architecture notes

## aws/
- AWS planning placeholders for deployment and cloud resources
- DynamoDB design guidance placeholders (no implementation)

## scripts/
- Utility and automation script placeholders for local/devops workflows
